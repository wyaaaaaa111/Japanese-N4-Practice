# ことば日和 · 日语学习网站

延续原版米白、墨绿视觉，以每日练习、教材路线、错题复习和学习统计陪伴个人日语学习。

## 当前内容

- 79 道练习：保留原有五题，另有 74 道项目原创题。其中本次按用户教材目录新增 39 道语法题。
- 教材路线：收到的 N4 目录第 1—101 项、七个单元，可按单元筛选与搜索。不能确认这是否是全书的完整目录，也不是官方 N4 语法清单。
- 当前 25 个目录项目有关联练习，13 个项目有原创学习卡。第一单元新增 39 题，每项 3 题，连同原先一道关联题共 40 题；这不代表每项的所有用法都已覆盖。
- 学习卡展示接续、用法、原创例句、翻译和易混提醒。目录来源和题目来源分开标注，原版五题的来源仍待核实。
- 其余目录项目如实显示待补充；书名、版次、正文页码均待核对。第11、12项的词形与第21、64项的简略结构需结合正文确认。

## 学习功能

每日目标可选 5 / 10 / 15 道不同题目，以语法、词汇、阅读 2:2:1 组题，到期复习与未练题优先。专项可按知识点和题数筛选。教材路线可进入知识点或单元练习；有题不等于已掌握，进度仅显示已练不同题目数。

提交后展示反馈和解析，普通练习与自测均可逐题回顾。错题立即进入待纠正列表，答对后按 1 / 3 / 7 / 14 / 30 天安排巩固；同日重复答对不升级间隔。这是轻量复习安排，不是掌握程度评定。

统计区分作答次数、不同题目覆盖、首次正确率，显示连续学习天数和近七天记录。阶段自测为 12 题、12 分钟原创小测，可返回修改，刷新续计时，交卷后统一解析，未答按错误计入该次自测成绩。它不含听力，不是完整 JLPT 模拟考试，原始成绩不等于官方换算分。

## 听力与资料边界

听力文本为原创，通过浏览器的日语合成语音播放。没有日语语音时会明确提示音频待补充，停用播放与提交，不使用英语或中文语音替代。本次测试浏览器无日语语音，实际日语播放未验收。正式授权音频、真人录音、教材正文和完整模考试卷仍待补充。

教材原图保存在用户自己的 Google Drive，未放入公开仓库。网站仅包含依据目录整理的知识点，以及另行编写的学习卡和题目。未声称取得教材完整正文或复用了教材原题。详细来源边界见 CONTENT_SOURCES.md。

## 学习记录

使用当前浏览器、当前来源下的 localStorage，键为 kotoba-n4-v2，schemaVersion 为 2。没有账号、云同步、学习分析上报或付费依赖。导出 JSON 可备份；导入先校验并显示新增数量，再确认合并，重复记录不重复计数、冲突记录拒绝导入，保留当前练习及本机学习目标。

存储不可用或空间不足时会提示未保存，损坏记录不自动覆盖。另一页面修改记录时暂停本页写入，防止互相覆盖。升级保留旧题号与题目版本，兼容此前 40 题版本的备份。

本地预览、GitHub Pages、不同浏览器之间不自动共享记录。如需把本地记录带到线上，请先在原预览的学习足迹导出，再在网站中导入。

## 本机运行

本机已有 Node.js，无需安装项目依赖。在本目录运行：

```sh
node preview.cjs
```

打开 http://127.0.0.1:4175/ 。Windows 可双击启动预览.cmd。服务仅监听本机，不对局域网开放。基础练习也可直接打开 index.html，但文件来源下的存储和语音支持因浏览器而异。没有网站离线缓存；Google Fonts 不可用时回退系统字体。

## 项目结构

- index.html / styles.css / app.js：页面、样式与学习流程。
- data/questions.js：原有 40 题与阅读、听力材料，稳定题号保留。
- data/curriculum.js：收到的 101 项目录、来源照片编号及原题关联。
- data/unit1.js：第一单元原创学习卡及 39 道新增题。
- lib/core.js：存储、备份校验、恢复、统计、复习和每日组题。
- tests/core.test.cjs：20 项必要数据与学习记录检查。

所有脚本采用相对路径，兼容 GitHub Pages 的仓库子目录，无需框架或构建步骤。部署静态页面时保留 data/ 和 lib/。
